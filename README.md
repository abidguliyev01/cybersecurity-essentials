# Cybersecurity Essentials

A structured learning guide for students and aspiring cybersecurity professionals, covering foundational knowledge, practical tools, and hands-on learning.

## 1. Build Your Foundations

Before using security tools, understand:

- **Networking:** IP addresses, ports, TCP/UDP, DNS, and HTTP/HTTPS.
- **Operating systems:** Linux commands, Windows basics, permissions, and processes.
- **Security fundamentals:** threats, vulnerabilities, risk, and the CIA triad.
- **Web fundamentals:** requests, responses, cookies, sessions, and authentication.

## 2. Explore Seven Security Tools

These tools cover several areas of security testing. They are a starting point, rather than a complete cybersecurity curriculum.

| Order | Tool | Main purpose | Learning focus |
|---|---|---|---|
| 1 | **Wireshark** | Capture and analyze network traffic | Understand protocols and packet contents |
| 2 | **Nmap** | Discover hosts, open ports, and services | Understand network exposure |
| 3 | **Burp Suite** | Inspect and test web application traffic | Understand HTTP requests and web security |
| 4 | **John the Ripper** | Audit passwords using offline hashes | Understand password hashes and weak passwords |
| 5 | **Hashcat** | Recover passwords from hashes using CPU/GPU resources | Explore password auditing and hardware acceleration |
| 6 | **Hydra** | Test login credentials against network services | Understand online password attacks and login protections |
| 7 | **Aircrack-ng** | Assess wireless network security | Understand Wi-Fi security and wireless auditing |

## 3. Follow a Practical Learning Process

For each tool:

1. Read its documentation and understand its purpose.
2. Learn the underlying networking or security concept.
3. Practice in a controlled lab.
4. Explain the results in your own words.
5. Identify the defensive measures that address the findings.

## 4. Document Your Practice

Use this structure for your lab notes:

- **Objective:** What are you trying to learn?
- **Environment:** Which authorized lab are you using?
- **Method:** What steps did you follow?
- **Findings:** What did you observe?
- **Defence:** How could the issue be prevented or detected?
- **Takeaway:** What did you learn?
